Groups

A tab can be in several groups at once. Tick to add, untick to remove; a dash means only some of the selected tabs are in it.

Keyboard shortcuts

← → ↑ ↓Move between cards
EnterOpen the card (as in Settings); Shift+Enter does the opposite (keep / remove)
x or SpaceSelect / unselect
Ctrl+ASelect everything shown
DeleteDelete the selection (or the highlighted card)
m / gMove to… / Groups…
n / eAdd a note / edit title
tTriage mode (one tab at a time)
Ctrl+ZUndo the last change
/Search
EscClear selection / close

Drag cards onto a group in the side panel to move them (hold Ctrl or Alt to add them to that group as well). Drag groups to reorder them, or onto the middle of another group to nest them.

Settings

Whatever you pick, each card also has “Open & remove” and “Open & keep” buttons, and Alt-click does the opposite of this setting.

Backups

Open Tab Stash in every new tab

Browsers only allow this as a fixed extension setting, so it is opt-in from the command line: run bash ~/tab-stash/newtab.sh on, then reload the extension. Use off to undo it.

Use Tab Stash as your home page

Browsers don't let extensions set this themselves. Copy the address below, then:

  1. Start-up page: → Open a specific page → Add a new page → paste.
  2. Home button: → turn on Show home button → Enter custom web address → paste.
